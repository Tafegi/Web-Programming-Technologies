# Технології WEB-програмування

Сайт із практичними роботами з дисципліни «Технології WEB-програмування». Усі роботи зібрані в одному репозиторії та доступні зі спільного головного меню.

**Автор:** Бабіч Андрій, група ШІД-21  
**Сайт:** [Практичні роботи](https://tafegi.github.io/Web-Programming-Technologies/)

## Практичні роботи

### Практична робота 1.1

Семантика HTML5, форматування тексту та вбудовування мультимедіа.

- **Секція 1:** зображення з обтіканням текстом (`float`), посилання на Google із підказкою, форматування тексту (`br`, `b`, `i`, `u`, `del`, кольори).
- **Секція 2:** локальне відео з атрибутами `autoplay`, `loop`, `muted` і `controls`.
- **Секція 3:** вбудоване відео YouTube з параметрами початку, завершення та повторення.

### Практична робота 1.2

Багатосторінковий сайт із навігацією та таблицею.

- Сторінка «Всі секції» та чотири окремі сторінки секцій.
- Спільна панель навігації між сторінками.
- Закріплена навігація для переходу до секцій головної сторінки.
- Кнопка повернення на початок сторінки.
- Таблиця з об’єднаними комірками за допомогою `colspan` і `rowspan`.
- Поділ CSS на спільні стилі та стилі окремих секцій.

### Практична робота 1.3

HTML-форма з вбудованою валідацією та адаптивним оформленням.

- Ім’я: обов’язкове текстове поле, до 20 символів.
- Email: обов’язкове поле з перевіркою формату адреси.
- Пароль: обов’язкове поле з прихованими символами.
- Вік: необов’язкове числове поле від 0 до 99.
- Стать: вибір одного з трьох варіантів.
- Група: випадаючий список.
- Біографія: багаторядкове текстове поле.
- Обов’язкова згода на обробку даних.
- Мітки, пов’язані з полями через атрибути `for` та `id`.
- Повідомлення про успішну валідацію за допомогою JavaScript.

Форма демонстраційна: дані на сервер не надсилаються.

### Практична робота 2.1

Сторінка з бічною навігацією та галереєю карток на основі CSS Flexbox.

- Бічна панель `aside` із посиланнями на головне меню та попередні практичні роботи.
- Основна частина `main` із контейнером карток.
- Картки фіксованого розміру 280 × 340 px.
- Кожна картка містить заголовок, квадратне зображення та опис.
- Центрування й рівномірний розподіл вмісту картки за допомогою Flexbox.
- Рамки, закруглені кути, курсор-рука та тінь при наведенні.
- Перенесення карток на наступні рядки через `flex-wrap`.
- Створення 100 копій початкової картки через `cloneNode(true)` — загалом 101 картка.
- Закріплена кнопка повернення на початок сторінки.
- Адаптивне розташування меню на вузьких екранах.
- Локальне SVG-зображення.

## Технології

- **HTML5** — семантична структура сторінок, мультимедіа, таблиці та форми.
- **CSS3** — оформлення, позиціювання, Flexbox, ефекти наведення та адаптивність.
- **JavaScript** — обробка події відправлення форми та дублювання карток.
- **GitHub Pages** — публікація сайту.
